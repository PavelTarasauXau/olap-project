# cut.md — чего в этом семестре не будет

| Не делаем                                     | Чем это грозит отчётам                                                                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Кластер ClickHouse (репликация, шардирование) | Работаем на одном узле. Данных мало, на ответы отчётов не влияет.                                                               |
| Потоковая загрузка (Kafka и т. п.)            | Данные обновляются пачкой из CSV. Отчёты отстают от «живых» продаж.                                                             |
| Возвраты и отмены чеков                       | Оборот считается как сумма всех продаж. Возвраты завысят общую выручку.                                                         |
| Учет клиентов и программы лояльности          | Нельзя построить RFM-анализ, посчитать персональный LTV и среднее число уникальных покупателей.                                 |
| Динамический складской учет (inventory)       | Нельзя отследить списания из-за истекшего срока годности (`shelf_life_days`), хотя сами дни хранения в `dim_product` добавлены. |
| Курсы валют и инфляция                        | Все суммы считаются в единой фиксированной условной валюте.                                                                     |
