# Паспорт витрины (P02 / зачёт)

ФИО: Тарасов Павел Витальевич · Дата: 30.10.2026 · Домен: розница (`retail_dw`)

Сырьё: `data/raw/` (поля описаны в [data/raw/README.md](https://www.google.com/search?q=data/raw/README.md)).

## 1. Бизнес-цель витрины (1–2 предложения)

Показать руководству сети магазинов, сколько зарабатывают магазины, регионы, категории товаров и как на продажи влияют промоакции и характеристики торговых точек (площадь, тип) по месяцам.

## 2. Grain (одна фраза)

Одна строка факта = **одна позиция в чеке: один товар в одном магазине за один день, с учетом примененной промоакции, проданным количеством и суммой.**

## 3. Fact-таблица(ы)

| Имя          | Grain                                               | Примечание                                                                                        |
| ------------ | --------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `fact_sales` | одна позиция в чеке: товар × магазин × день × промо | ключ `sale_id`; ссылки на `date_id`, `store_id`, `product_id`, `promo_id`; возвратов в данных нет |

## 4. Меры

| Мера                        | Тип (sum ok / нет)      | Определение                                                           |
| --------------------------- | ----------------------- | --------------------------------------------------------------------- |
| `amount`                    | sum ok                  | сумма продажи по позиции с учетом скидки, `DECIMAL(12,2)`             |
| `qty`                       | sum ok                  | количество проданных единиц товара                                    |
| цена продажи                | **нет**                 | в таблице не хранится; по группе считать как `sum(amount) / sum(qty)` |
| себестоимость (`unit_cost`) | **нет** (в справочнике) | хранится в `dim_product`, используется для расчета маржинальности     |

## 5. Измерения

| Dim             | Ключ                 | Важные атрибуты                                                                                      | SCD1 / SCD2 / нет                                                        |
| --------------- | -------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `dim_store`     | `store_id`           | `store_name`, `city`, `region`, `store_type`, `area_sq_m`                                            | SCD1: при исправлении названия, типа или площади данные перезаписываются |
| `dim_product`   | `product_id`         | `product_name`, `category`, `brand`, `production_date`, `shelf_life_days`, `unit_cost`, `unit_price` | SCD2: категория и бренд могут меняться со временем (реализация на З06)   |
| `dim_date`      | `date_id` (YYYYMMDD) | `full_date`, `year`, `month`, `month_name`, `day_of_week`                                            | нет: календарь статичен                                                  |
| `dim_promotion` | `promo_id`           | `promo_name`, `discount_percent`, `promo_type`                                                       | SCD1: справочник видов скидок и акций                                    |

## 6. Три бизнес-вопроса (с учетом новых данных)

1. Какой суммарный оборот и маржинальность (`amount - unit_cost * qty`) приносят разные типы магазинов (`store_type`)?
2. Как наличие промоакций (`promo_type`) влияет на средний объем проданных единиц товара (`qty`) за чек?
3. Какой оборот дают различные категории товаров с учетом их срока годности и брендов?

Запросы: [sql/analytics.sql](https://www.google.com/search?q=sql/analytics.sql)

## 7. Эталонный SQL одной метрики

Главная метрика: **оборот** = сумма `amount` по всем строкам факта.

```sql
SELECT sum(amount) AS total_turnover
FROM fact_sales;

```
